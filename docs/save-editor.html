How to use it

1. Close RetroArch, copy the card file somewhere safe, then load it here.

2. Pick a save, set the room (and the story step if the room only exists later in the story), and save. You get a .zip holding the edited card under its original name.

3. Unzip it over the card in RetroArch's saves folder and load the save in game.

Cards saved by older versions of this editor show "checksum wrong": load the card, pick the save and save it again (no changes needed) to repair it.

Jumping ahead without the story's events can stop scenes or doors from working in that save. That is expected; keep it for testing only.
